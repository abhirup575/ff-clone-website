# 🎮 FF Clone Website

Welcome to my **FF Clone Website** project! 🚀

This project is a **Free Fire-inspired clone website** that I created while learning and practicing **Git and GitHub**. The main purpose of this project was to understand how to manage a web development project using Git, track changes, create commits, and work with repositories on GitHub.

## 📌 About the Project

The **FF Clone Website** is a simple website inspired by the design and style of the popular battle-royale game **Free Fire**. I created this project as part of my Git learning journey and used it to practice both **web development concepts** and **version control with Git**.

While building this project, I experimented with different website elements, layouts, styling, and Git commands. It helped me understand how a project can be developed step-by-step while keeping track of every important change.

## 🎯 Purpose of This Project

The main goals of this project were:

* 🧑‍💻 Practice my web development skills
* 🌐 Create a Free Fire-inspired website
* 📚 Learn and practice Git
* 🔄 Understand version control and change tracking
* 📁 Learn how to manage project files using Git
* 💾 Practice making commits and maintaining project history
* 🚀 Get familiar with uploading and managing projects on GitHub

## 🛠️ Technologies Used

The project was created using basic web development technologies such as:

* **HTML** – Used to create the structure of the website
* **CSS** – Used to design and style the webpage
* **JavaScript** – Used where required to add interactivity
* **Git** – Used for version control
* **GitHub** – Used to store and manage the project repository

## 📖 What I Learned

Working on this project gave me practical experience with Git and helped me understand concepts such as:

* Initializing a Git repository
* Adding files to Git
* Creating commits
* Checking project status
* Viewing changes
* Working with GitHub repositories
* Pushing local projects to GitHub
* Maintaining a project using version control

This project was not only about creating a website but also about understanding how developers manage their code and track their progress using Git.
